# homebrew-tap

Homebrew tap for KKFetch and tools.

## Installation

```bash
brew tap kk376/tap
brew install kkfetch
```

Or install directly:

```bash
brew install kk376/tap/kkfetch
```

## Formulas

- **kkfetch**: Fast, lightweight Linux system information fetch CLI written in Rust by Kushagra Kumar (kk376)
